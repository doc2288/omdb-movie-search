# 🎬 OMDb Movie Search

Современное веб-приложение для поиска фильмов, сериалов и эпизодов с использованием OMDb API. Построено на Remix, React и TypeScript с поддержкой темной темы.

## ✨ Особенности

- 🔍 Поиск фильмов, сериалов и эпизодов
- 🎭 Фильтрация по жанрам, типу контента и году выпуска
- 🌙 Темная/светлая тема с автоматическим определением системных настроек
- 📱 Адаптивный дизайн для всех устройств
- ⚡ Кэширование запросов для улучшения производительности
- 🎨 Современный UI с плавными анимациями
- ♿ Улучшенная доступность (accessibility)

## 🚀 Быстрый старт

### Требования

- Node.js >= 18.0.0
- npm или yarn
- API ключ OMDb (бесплатный на [omdbapi.com](https://www.omdbapi.com/apikey.aspx))

### Установка

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd omdb-movie-search
```

2. Установите зависимости:
```bash
npm install
```

3. Создайте файл `.env` в корне проекта:
```env
OMDB_API_KEY=your_api_key_here
```

4. Запустите сервер разработки:
```bash
npm run dev
```

5. Откройте [http://localhost:5173](http://localhost:5173) в браузере

## 🔧 Конфигурация

### Переменные окружения

- `OMDB_API_KEY` - API ключ для OMDb (обязательно)

### Кэширование

Приложение использует LRU кэш для хранения деталей фильмов:
- Максимум 500 записей
- TTL: 10 минут

## 🎨 Кастомизация

### Темы

Темы настраиваются в `tailwind.config.ts`. Поддерживаются:
- Светлая тема
- Темная тема
- Автоматическое определение системных настроек

### Стили

Основные стили находятся в `app/styles/tailwind.css`. Анимации и кастомные классы определены в Tailwind конфигурации.

## 🐛 Решение проблем

### Ошибка "OMDB_API_KEY is required"

Убедитесь, что файл `.env` существует в корне проекта и содержит правильный API ключ.

### Проблемы с кэшированием

Кэш очищается автоматически через 10 минут. Для принудительной очистки перезапустите сервер.
